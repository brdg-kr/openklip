# OpenKlip 미디어 인덱싱 작업 메모

작성일: 2026-08-28

## 진행한 내용

- MCP에서 동영상 URL 인제스트, 작업 상태 조회, 멤버 프로필 생성과 인덱스 제어가 가능하도록 구현했다.
- URL 인제스트 작업은 다운로드와 프로젝트 생성뿐 아니라 얼굴·장면 인덱스까지 완료되어야 done이 된다.
- YuNet과 SFace로 대상 멤버 출현 구간을 찾고, SigLIP2로 전체 화면·멤버 주변·멤버 중심 장면을 검색한다.
- 기본 4fps 얼굴 분석에 장면 전환과 모호한 경계를 10fps로 다시 검사하는 절차를 추가했다.
- 작은 얼굴과 흐린 얼굴을 제외하고, 같은 그룹 멤버 또는 명시적 다른 인물 사진을 하드 네거티브로 사용한다.
- 하드 네거티브가 없으면 높은 유사도라도 확정하지 않고 ambiguous로 남긴다.
- 한글 질문을 원문으로 유지하고, Agent가 필요할 때만 충실한 영어 번역과 시각 특징 질의를 최대 2개 추가하는 target-moment-search 스킬을 만들었다.
- 여러 언어 질의를 한 번에 임베딩하고 RRF로 결합하며, 결과에 질의별 점수와 순위를 반환한다.
- 원격 프로필 이미지는 20MB 한도 안에서 스트리밍하며, 사설 주소·위험한 리다이렉트·지원하지 않는 이미지 형식을 거부한다.
- 소스 영상, 멤버 프로필 또는 모델 계약이 바뀌면 기존 인덱스를 사용하지 않도록 했다.
- 구현은 origin/main에 푸시했다.
  - c5debf2: MCP URL 인제스트와 대상 멤버 미디어 인덱싱
  - 5531cd4: Next 라우트 타입 검사 수정

## 검증 상태

- 린트와 타입 검사 통과
- 전체 테스트 2,769개 통과, 14개 조건부 제외, 실패 0개
- 멀티캠 통합 테스트와 Agent 스모크 테스트 통과
- 이 실행환경에서는 Turbopack이 내부 로컬 포트를 열 수 없어 프로덕션 빌드만 환경 제한으로 완료하지 못했다.
- 얼굴 임계값은 아직 실제 아이돌 영상으로 보정하지 않은 기본값이다.

## 앞으로 할 일

1. 실제 대상 멤버의 선명한 정면·측면·표정 사진과 같은 그룹 멤버 하드 네거티브로 프로필을 만든다.
2. 실제 원본 영상을 MCP url_ingest로 넣고 인덱스가 done까지 완료되는지 확인한다.
3. 실제 영상에서 멤버 출현 구간의 오탐·누락과 경계 오차를 사람이 확인한다.
4. 동일한 장면 질문을 한글 단독, 영어 단독, 한글+영어 융합으로 비교해 검색 품질을 측정한다.
5. 측정 결과를 기준으로 얼굴 점수·마진·화질 기준과 한글/영어 질의 정책을 조정한다.
6. 검색 결과를 이용해 주제 후보와 편집 시작·종료 구간을 제안하는 Agent 작업 단계를 연결한다.
7. 그 다음 단계에서 선택한 구간을 OpenKlip 프로젝트 편집과 자막 초안 작업으로 넘긴다.

이 메모는 구현 진행 상황을 빠르게 다시 확인하기 위한 기록이다.
